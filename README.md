# Albireo

Albireo is a modern dark-mode financial SaaS application designed for prop firm traders. It bridges Software Engineering Discipline with Market Trading Precision by providing verified drawdown simulation, COT sentiment visualizer, trade journaling, and a prop firm rule directory.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
